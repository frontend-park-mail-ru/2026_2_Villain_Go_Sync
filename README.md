## Запуск

```bash
npm install
npm run dev        # dev-сервер на http://localhost:8000, пересобирает при изменениях
npm run build      # сборка для прода в папку dist/
npm run typecheck  # проверка типов TypeScript
npm run lint       # проверка линтером (npm run lint:fix — исправить автоматически)
```

Настройки сервера задаются переменными окружения или файлом `.env` в корне проекта (образец — `.env.example`).
Переменные окружения имеют приоритет над файлом; после изменения `.env` сервер нужно перезапустить.

- `PORT` — порт фронтенда, по умолчанию `8000`;
- `API_URL` — адрес бэкенда, по умолчанию `http://localhost:8080/api`. Фронтенд обращается к нему напрямую
  и передаёт cookie сессии, поэтому на бэкенде для адреса фронтенда должен быть разрешён CORS.

## Админка OnlineConf

После `npm run dev` каталог ключей доступен по пути `/admin/onlineconf/` на адресе dev-сервера.
Сначала войдите в HireNoon под аккаунтом администратора OnlineConf. Для локального запуска открывайте
фронт и продуктовый API через один hostname, например `localhost`, чтобы браузер передавал cookie сессии.

Webpack проксирует `/api/onlineconf/` на `ONLINECONF_DEV_TARGET` (по умолчанию
`http://127.0.0.1:8081`). Если сервис слушает другой порт, задайте `ONLINECONF_DEV_TARGET` в `.env`
и перезапустите dev-сервер.

При деплое веб-сервер должен отдавать `dist/admin/onlineconf/index.html` для `/admin/onlineconf/`,
а запросы `/api/onlineconf/` передавать сервису OnlineConf с исходным путём. Остальной продуктовый API
по-прежнему обслуживает HireNoon. Админка использует cookie продуктовой сессии и CSRF-заголовок при записи.

Контракт описан в `docs/onlineconf.openapi.yaml` бэкенда. Каталог загружает `/admin/me`, `/admin/scopes`
и `/admin/keys` с префиксом `/api/onlineconf`. Конфиги и флаги сохраняются через `/admin/configs`
и `/admin/flags`. Персональные настройки применяются отдельными запросами
к `/admin/flags/{id}/overrides/{user_id}`. Если часть запросов завершилась ошибкой, редактор сохраняет
введённые данные и повторная попытка применяет оставшиеся изменения к тому же флагу.

В каталоге доступны управление областями, история изменений и удаление ключей. В карточке флага
можно проверить результат для конкретного ID пользователя. Владелец управляет доступом в разделе
«Администраторы».

## Динамические настройки HireNoon

После входа продуктовый фронтенд читает `GET /api/runtime-config` и обновляет настройки каждые 15 секунд.
Контракт описан в `docs/runtime-config.openapi.yaml` бэкенда.

- `vacancy.max_categories` задаёт лимит направлений и тегов вакансии.
- `vacancy.creation_enabled` управляет созданием вакансии.
- `application.applications_enabled` управляет отправкой отклика.

Временный сбой запроса сохраняет последний полученный снимок текущей сессии. При выходе или смене
пользователя снимок сбрасывается. Новые значения меняют кнопки и подсказки, а введённые поля остаются в форме.
